# Practical Statistics for Data Scientists - Code Reproduction & Theoretical Deep-Dive

Repositori ini dibuat untuk memenuhi tugas mata kuliah Machine Learning & Deep Learning dengan melakukan reproduksi kode dan penjelasan teori dari buku **Practical Statistics for Data Scientists** (O'Reilly).

## Ringkasan Bab (Chapter 1–4)

### Chapter 1: Exploratory Data Analysis (EDA)
Membahas teknik statistik deskriptif untuk mengukur pemusatan data (mean, trimmed mean, median), variabilitas (standar deviasi, IQR, MAD), eksplorasi distribusi data (boxplot, persentil), serta hubungan antar variabel (korelasi dan scatterplot).

### Chapter 2: Data and Sampling Distributions
Membahas konsep random sampling, bias seleksi, Teorema Limit Terpusat (Central Limit Theorem), teknik resampling Bootstrap untuk mengukur rentang ketidakpastian, dan pembuatan Confidence Intervals (95%).

### Chapter 3: Statistical Experiments and Significance Testing
Membahas eksperimen A/B Testing, pengujian hipotesis (Null vs Alternative Hypothesis), Permutation Test, signifikansi statistik, p-value, t-Test, ANOVA, dan Uji Chi-Square untuk data kategorik.

### Chapter 4: Regression and Prediction
Membahas implementasi Simple & Multiple Linear Regression dengan metode Least Squares, evaluasi performa model menggunakan RMSE dan R-squared, serta analisis diagnostik residual (heteroskedastisitas).
